# Workstation-Mac Home Folder Layout (+333 GB Reclaimed)

> [!TIP]
> **The Golden Rule on `workstation-mac`**: Every file has one home. Code repos go in `~/Projects/`, readable notes go in `~/Documents/`, cold backups go in `~/Archives/`, and AI agents are never allowed to dump scratch folders into the home root (`~`).

---

## 1. Where Everything Lives (`~`)

| Folder | What Belongs Here | What Is Strictly Banned Here |
|---|---|---|
| **`~/Projects/`** | **All code repositories**, Swift packages, Python apps, and active dev work (`mlx-whisper-gui`, `MacVoiceLogger`, `VoiceDiarizer`, `no-cost-router`, `hermes`, `WritingPeersFusion`). | Personal docs or cold `.tar.gz` dumps. |
| **`~/Documents/`** | **Readable documents, notes, and runbooks only** (`Operations/`, `Agent-History/`). | Active git repos, compiled binaries, network dumps (`.har`), or giant `.zip` archives. |
| **`~/Archives/`** | **Cold storage**, old migration bundles, and diagnostic network captures. | Active code or live configs. |
| **`~/Storage/`** | Local Apple Silicon MLX & [[20.02-LoRA-Weight-Adapter]] weights (`qwen3.5-9b-hermes-v2-oQ5e`, `bonsai-8b-ternary`). | — |
| **`~/bin/`** | Personal command-line scripts on `$PATH`. | — |
| **`~/.agents/`** | This **Johnny.Decimal knowledge vault** (`knowledge/`), 31 shared skills (`skills/`), and unified chat transcripts (`sessions/`). | — |

---

## 2. How We Reclaimed +333 GB on Oct 27, 2026

Our 1 TB laptop SSD had dropped to **only 20 GB free (98% full)**. In one evening pass, we restored **353 GB free (61% used)** by cleaning up five hidden space hogs:
1. **54 GB of unfinished Git pack files** stuck inside a backup folder.
2. **40 GB abandoned Google Drive temp upload file** hidden in `~/Library/Application Support/Google/DriveFS/`.
3. **126 GB of duplicate / oversized local AI models** (unused 35B models and duplicate GGUF files that belonged on `gpu-server`).
4. **11.4 GB of unused Android tablet emulators** (`~/.android/avd/`).
5. **Thinned local Time Machine snapshots** so macOS immediately returned the freed blocks to APFS.
