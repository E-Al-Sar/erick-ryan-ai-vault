# macOS Accessibility (AX) UI Reader & Network Diagnostics

## 1. Reading Desktop App Lists Without Stealing Focus (`zoom-participants-ax.swift`)

> [!TIP]
> **Why This Is Cool**: Most desktop automation tools click on windows and hijack your mouse/keyboard. Our native Swift helper uses the macOS Accessibility (`ApplicationServices` / `AXUIElement`) API to read UI lists in the background **without ever stealing window focus**.

### How It Works
1. Finds the running desktop app process (`us.zoom.xos`) and locates its open list panel (`AXOutline`).
2. Quietly moves the list's scroll value in the background (with zero mouse clicks or window activation), reading each row's label as it scrolls.
3. Restores the exact original scroll position when finished and outputs a clean, deduplicated list (tested on live 200+ item lists).

## 2. Network Traffic Debugging Rules (Proxyman)

When inspecting how a desktop app talks to its web APIs:
- Scope capture strictly to the target app's domains rather than proxying all system traffic.
- **Privacy Guardrail**: Never commit raw network captures (`.har` or `.proxymanlogv2`) into Git or `~/Documents/` (see [[30.05-Emac-Filesystem-and-Home-Layout]]). Always strip auth headers and session tokens first.
