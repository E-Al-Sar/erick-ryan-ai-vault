# Host Topology MOC (Which Machine Does What)

Per [[40.01-Agent-Policy]] (`WORKSTYLE.md`), **every machine has a distinct job—agents never confuse files on the laptop with files on the server.**

---

## Our Environments at a Glance

| Machine / Environment | Hardware | Main Job | When Work Goes Here |
|---|---|---|---|
| **`workstation-mac` (Local Laptop)** | MacBook Pro (Apple M5 Pro, 20 GPU cores, 24 GB Unified RAM, 1 TB SSD) | Daily driver; runs [[10.02-Antigravity-AGY]], [[10.03-Codex-CLI-and-Spark]], [[10.04-Hermes-Agent]], [[10.05-OpenCode-and-Maestri]], and local [[20.03-Inference-Provider]] **oMLX**. Holds `~/.agents/` and [[40.05-TouchID-Redaction-Vault]]. | Default for desktop apps, code repos (`~/Projects/`), local Apple Silicon models, and orchestrating across agents. |
| **Git Worktree (on `workstation-mac`)** | Separate Git folder on the laptop | Keeps two coding tasks from stepping on each other's uncommitted files while still sharing the same Mac. | Running two code branches at the same time safely. |
| **`gpu-server` (24/7 Linux Server)** | Dedicated Desktop Server (Intel CPU + **NVIDIA RTX 4070 12 GB VRAM** + multi-drive NVMe/SATA storage pool) | Runs 24/7 **Ollama** ([[20.03-Inference-Provider]]), trains [[20.02-LoRA-Weight-Adapter]] packs (`v2`/`v3`), runs [[50.01-Evaluation-Harness]] crash tests, and stores the master backup of 794 unified chat sessions. | Heavy GPU fine-tuning, automated benchmark suites (`H01–H06`, `T01–T15`), and background Docker services. |
| **Cloud Container** | Temporary Linux sandbox in the cloud | Has only a cloned Git repo—zero access to local files, passwords, or our home network. | Isolated repo unit tests and pull request previews. |
