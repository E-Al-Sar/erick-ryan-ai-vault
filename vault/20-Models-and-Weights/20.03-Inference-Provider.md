# Inference Provider (The Local Model Servers)

## What It Is in Plain English

An **Inference Provider** is the background server app that loads a [[20.01-Base-Model]] (plus an optional [[20.02-LoRA-Weight-Adapter]]) into memory and gives our [[10.01-Agent-Harness]] apps a local URL (`/v1/chat/completions`) to talk to.

---

## Our Active Model Servers

| Server Name | Which Machine | What It Does | Connected Apps |
|---|---|---|---|
| **oMLX** | `workstation-mac` | Runs Apple Silicon MLX models locally in unified RAM (`Qwen3.5-9B`, `S1-mini`, `Defiant-Fable`). Tuned for high speed in [[50.06-2026-09-09-oMLX-Qwen-Throughput-and-Cache-Analysis]]. | [[10.04-Hermes-Agent]], [[10.05-OpenCode-and-Maestri]] |
| **Ollama** | `gpu-server` | Runs 24/7 on the RTX 4070 (12 GB VRAM) serving `hermes-eserv:v2`, `hermes-qwen35-uncensored:9b`, and `qwen2.5-coder:7b`. | [[10.04-Hermes-Agent]] (including MoA councils) |
| **Loopback Eval Server** (`server_loopback.py`) | `gpu-server` | Temporary test server spun up only when running [[50.01-Evaluation-Harness]] crash tests on [[20.02-LoRA-Weight-Adapter]] checkpoints. | [[50.01-Evaluation-Harness]] |
| **LM Studio (`llmster`)** | Both machines | Backup server for testing downloaded GGUF models on demand ([[30.02-Homelab-LLM-Orchestration]]). | Cursor / Cline / Manual tests |

## Two Simple Rules That Save Headaches

1. **Don't Let `oMLX` Look for Ghost Computers**:
   - When running solo on `workstation-mac`, keep `"distributed_inference_enabled": false` in `~/.omlx/settings.json`. Otherwise it wastes time every 5 seconds trying to ping a second Mac that isn't plugged in ([[50.06-2026-09-09-oMLX-Qwen-Throughput-and-Cache-Analysis]]).
2. **Turn Off the Test Server When Crash Tests Finish**:
   - After running `server_loopback.py` on `gpu-server`, always shut it down so all 12 GB of RTX 4070 video memory go back to **Ollama** ([[50.02-2026-10-19-Session-Review-and-Quota-Audit]]).
