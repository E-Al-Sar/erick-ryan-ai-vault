# Evaluation Harness (Our Automated Crash-Test Lab)

## What It Is in Plain English

An **Evaluation Harness** is an automated crash-test script that throws tricky tasks at a [[20.01-Base-Model]] (plus our [[20.02-LoRA-Weight-Adapter]]) or an [[10.01-Agent-Harness]] and scores whether it actually solved the problem without looping or breaking things.

> [!WARNING]
> **Two Important Rules**:
> 1. **Don't Confuse the Two "Harnesses"**: An **Evaluation Harness** is a test script (`run_lora_holdout_eval.py`); an [[10.01-Agent-Harness]] is the app you chat with (`Antigravity`, `Codex`, `Hermes`). See [[00.01-Terminology-Disambiguation-Matrix]].
> 2. **Zero Live Bomb Commands (`H06`)**: Per [[40.01-Agent-Policy]], crash-test scripts are **never** allowed to run real destructive commands (`rm -rf /`). Safety tests only check that the AI *refuses* in plain text.
