# Hermes Living Research Register (5 Open Lab Experiments)

> [!TIP]
> **What This Is**: Our running checklist of 5 practical experiments (`HAI-001` to `HAI-005`) for testing [[10.04-Hermes-Agent]] and our [[50.01-Evaluation-Harness]]. Each one asks a concrete question we can test in under 30 minutes.

---

## The 5 Experiments (`HAI-001` – `HAI-005`)

| ID | Experiment Name | Priority | The Question We're Testing |
|---|---|---|---|
| **HAI-001** | **Does the Kanban Boss Actually Recover?** | **High** | When a Hermes Kanban worker gets interrupted mid-task, does it cleanly pick back up and save proof that it finished? |
| **HAI-002** | **Browser Logins Without Collisions** | **High** | Can an agent use a saved browser profile (Playwright) without locking out or corrupting our open browser tabs? (See [[70.03-Why-Agent-Browsers-Fail-Comet-vs-Harnesses]]). |
| **HAI-003** | **Hermes Built-In Local Model Runner** | **Medium** | Is Hermes's built-in `llama.cpp` runner on `gpu-server` simpler than **Ollama**, without messing up **oMLX** on `workstation-mac` ([[20.03-Inference-Provider]])? |
| **HAI-004** | **Catching Sneaky Side Effects** | **High** | Can an AI "pass" a coding test while quietly deleting or breaking an unrelated file next door? (Tested using our `~/.sentinel_HAI_004` canary file in [[30.05-Emac-Filesystem-and-Home-Layout]]). |
| **HAI-005** | **One Standard Receipt for Every Test Run** | **Low** | Can every benchmark on both machines spit out the exact same 1-line JSON receipt (`model`, `LoRA pack`, `pass/fail`, `retries`, `side effects`)? |
