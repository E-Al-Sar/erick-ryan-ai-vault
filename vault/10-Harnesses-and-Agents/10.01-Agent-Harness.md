# Agent Harness (The Apps We Talk To)

## What It Is in Plain English

An **Agent Harness** is the **app, CLI, or code editor you actually type into**. A raw [[20.01-Base-Model]] is just a brain in a jar—it can only predict text. The **Agent Harness** gives that brain hands and eyes by doing three things:
1. **Builds the Prompt**: Combines your message with our always-on house rules ([[40.01-Agent-Policy]]) and any relevant how-to playbooks ([[40.03-Agent-Skill]]).
2. **Runs Tools**: Watches for `<tool_call>` tags from the model, runs terminal commands or reads files safely, and feeds the results back to the model.
3. **Saves the Chat**: Writes the conversation log to disk so [[40.04-Session-Ingestor]] can add it to our searchable memory.

> [!WARNING]
> **Quick Name Check** (see [[00.01-Terminology-Disambiguation-Matrix]]):
> - **Agent Harness** = the interactive app (`Antigravity`, `Codex`, `Hermes`, `OpenCode`).
> - **[[50.01-Evaluation-Harness]]** = the automated crash-test script (`run_lora_holdout_eval.py`).
> - **[[40.02-Policy-Sync-Target]]** = the rules file (`AGENTS.md` / `SOUL.md`) inside each app.
