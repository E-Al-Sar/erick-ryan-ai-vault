# Codex CLI & Spark — Precision Code & 2-Minute Sanity Checks

## What Role It Plays

**Codex** (`/Applications/ChatGPT.app` / `~/.codex/`) is OpenAI's coding [[10.01-Agent-Harness]]. In Erick's setup, it runs `Luna` (default), `Sol` / `Terra` (deep reasoning when explicitly requested), plus fast, disposable **`Spark`** checks.

## How We Split Work Between Main Codex and `Spark`

Per [[40.01-Agent-Policy]] (and [[70.01-Intelligence-Fit-to-Form-MOC]]):
- **The Main Agent (`Luna` / `Sol` / `Terra`)**: Owns final decisions, tricky algorithm work, and bug-hunting code reviews (`review-agent` in [[40.03-Agent-Skill]]).
- **The Fast Scout (`Spark`)**: Called via a one-line terminal command:
  ```bash
  codex exec -p spark --ephemeral
  ```
  We use `Spark` for **one bounded, 2-to-10 minute question at a time**—like a trade-off table (`DECIDE`), a design sketch (`DESIGN`), a short summary (`BRIEF`), a post-mortem (`RETRO`), or a quick pitch (`PITCH`).
  - **Why this works**: `Spark` can challenge the main agent or spot a blindspot quickly without burning main quota or taking over the whole project.

## How It Connects to the Vault

- **Shared Rules**: `~/.codex/AGENTS.md` (updated automatically from [[40.01-Agent-Policy]] via [[40.02-Policy-Sync-Target]]).
- **Shared Skills**: `~/.codex/skills/` (linked to [[40.03-Agent-Skill]]).
- **Saved Chats**: 394 past Codex sessions are indexed into our searchable archive via [[40.04-Session-Ingestor]].

## Quota Rule of Thumb

In [[50.02-2026-10-19-Session-Review-and-Quota-Audit]], we found that letting Codex sit in 45-second `sleep` loops waiting on server jobs burned through OpenAI's 5-hour usage limit. Now, long-running multi-file jobs go to [[10.02-Antigravity-AGY]] or local [[10.04-Hermes-Agent]].
