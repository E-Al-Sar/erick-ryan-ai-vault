# Why Agent Products Break (From *"Why I Canceled Comet"* to Our Crash Tests)

> [!TIP]
> **Ryan's Core Finding in *"Why I Canceled Comet"***:
> Even when an AI company has a strong underlying search/model engine (like Perplexity's **Sonar**), the **product & behavior layer** (like **Comet**) falls apart when it drops user constraints, loops clumsily on UI actions, or fights the user's actual workflow.

---

## 1. Every Failure Mode in Consumer AI Has a Twin in Our Lab

When we audited our own agents on Oct 19 ([[50.02-2026-10-19-Session-Review-and-Quota-Audit]] and [[50.03-2026-10-19-Tri-Agent-Hardening-Plan-and-Walkthrough]]), we ran into the exact same failure patterns that break products like Comet:

| What Breaks in Consumer AI (e.g. Comet) | What We Caught in Our Lab | How We Fixed It in This Vault |
|---|---|---|
| **Blind Looping**: The agent keeps clicking or searching the same dead end until the user rage-quits. | **Failure `H05`**: [[10.04-Hermes-Agent]] ran `search_files` 6 times in a row on a missing file until it ran out of turns. | **2-Search Hard Cap**: Added to [[40.01-Agent-Policy]] AND trained into [[20.02-LoRA-Weight-Adapter]] `v3` so the bot stops after 2 empty tries and reports cleanly. |
| **Dropped / Mangled Tool Calls**: The agent tries to do two things at once and breaks its own formatting. | **Failure `T02` & JSON Double-Escaping**: Unclosed `<tool_call>` tags or double-escaped JSON strings. | **Format Guard**: Fixed via `T02` training traces in [[20.02-LoRA-Weight-Adapter]] `v3` and Python deep-merge in [[50.05-2026-09-26-Hermes-JSON-Double-Encoding-Postmortem]]. |
| **Silent Collateral Damage**: The agent "completes" your task while quietly messing up your other tabs, logins, or files. | **Research Item `HAI-002` & `HAI-004`**: Browser profile lock collisions and out-of-scope file edits. | **Isolated Browser Profiles & Canary Files**: Documented in [[50.04-2026-10-14-Hermes-Living-Research-Register]] and [[30.05-cluster-node-Filesystem-and-Home-Layout]] (`.sentinel_HAI_004`). |
| **Semantic Search Missing Exact Words**: Vector search returns "vaguely similar" fluff while missing the exact name or setting you typed. | **Retrieval Audit `50.07`**: Pure vector search (`ane-search`) only hit **40% Recall@5** on exact technical terms vs. **85% for BM25**. | **Hybrid Search (BM25 + RRF)**: Documented in [[40.06-ANE-Hybrid-Inference-and-Retrieval]] and [[50.07-2026-10-20-ANE-Retrieval-Harness-and-Contention-Audit]]. |

## 2. How We Can Turn Product Teardowns into a Shared Benchmark

Right now, [[50.01-Evaluation-Harness]] tests:
- **`H01–H06`**: Can the agent edit files, read logs, run code, stop looping, and refuse dangerous commands?
- **`T01–T15`**: Does the model format tool calls cleanly and verify edge cases?

**What's missing—and where Ryan's eye is unmatched**:
- A **Behavioral & Product Layer Suite (`B01–B10`)** inspired by *"Why I Canceled Comet"*:
  - **`B01` (Constraint Persistence)**: Does the agent still obey a negative rule (*"Don't use bullet points"*) on turn 6 of a messy conversation?
  - **`B02` (Anti-Sycophancy / Anti-Contrarianism)**: When the user gives a slightly flawed idea, does the agent fix the flaw calmly without lecturing or groveling ([[70.02-Sycophancy-vs-Reflexive-Contrarianism]])?
  - **`B03` (Graceful Handoff)**: When a browser or tool hits a login wall or ambiguity, does it hand control back cleanly (`HAI-002` in [[50.04-2026-10-14-Hermes-Living-Research-Register]])?
