# TouchID Redaction Vault (657 Keys Locked in macOS Keychain)

## What It Is in Plain English

When you're debugging with an AI, it's easy for an API key, password, or token to end up in a chat log. If you just delete the key when cleaning logs, you might lose a token you actually needed; if you leave it in the log, you can't safely use your chats for search or [[20.02-LoRA-Weight-Adapter]] fine-tuning.

Our script (`~/.agents/scripts/vault.py`) solves both problems at once:
1. Whenever [[40.04-Session-Ingestor]] spots a secret in any chat log, it replaces the secret in the text with a clean placeholder: `[REDACTED: <label>]`.
2. Before erasing it from the text, `vault.py` saves the real key inside the **native macOS Keychain (`Passwords.app`)** under **`AgentRedactedVault`**, locked behind your fingerprint (**TouchID**).

- **Total Keys Rescued & Locked**: **657 unique credentials** safely stripped from chat logs and stored in macOS Keychain.
