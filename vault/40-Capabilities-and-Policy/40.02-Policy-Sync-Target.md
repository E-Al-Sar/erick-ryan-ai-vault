# Policy Sync Target (Keeping 6 AI Apps on the Same Page)

## What It Is in Plain English

Every [[10.01-Agent-Harness]] looks for its system rules in a different file (`AGENTS.md`, `SOUL.md`, `CLAUDE.md`, etc.). A **Policy Sync Target** is one of those destination files.

Whenever we edit our master rulebook ([[40.01-Agent-Policy]] / `WORKSTYLE.md`), running `sync_policy.py` stamps the exact same rules block into all 6 apps and checks its SHA-256 fingerprint so zero apps ever drift out of date.

> [!IMPORTANT]
> **Quick Name Check** (see [[00.01-Terminology-Disambiguation-Matrix]]):
> Because the config file is named `adapters.json`, it's easy to confuse a **Policy Sync Target** with a [[20.02-LoRA-Weight-Adapter]] (GPU model weights) or a [[40.04-Session-Ingestor]] (chat log parser).

## The 6 Files Kept in Sync Automatically

| # | Destination File | Which AI App Reads It ([[10.01-Agent-Harness]]) | How It's Stamped |
|---|---|---|---|
| 1 | `~/.codex/AGENTS.md` | [[10.03-Codex-CLI-and-Spark]] | Added at top (`prepend`) |
| 2 | `~/.hermes/SOUL.md` | [[10.04-Hermes-Agent]] (Default Profile) | Added at bottom (`append`) |
| 3 | `~/.hermes/profiles/mac-orchestrator/SOUL.md` | [[10.04-Hermes-Agent]] (`mac-orchestrator`) | Added at bottom (`append`) |
| 4 | `~/.gemini/config/rules/AGENTS.md` | [[10.02-Antigravity-AGY]] | Added at top (`prepend`) |
| 5 | `~/.agents/rules/autonomy.md` | Shared `~/.agents` rule | Added at bottom (`append`) |
| 6 | `~/.config/opencode/opencode.jsonc` & `~/.claude/CLAUDE.md` | [[10.05-OpenCode-and-Maestri]] & Claude Code | Linked via instructions path |

---

## One-Line Sync & Drift Check

```bash
# Stamp WORKSTYLE.md into all 6 targets:
python3 ~/.config/agent-policy/sync_policy.py

# Check if any file drifted out of sync (returns {"adapters": 6, "drift": []}):
python3 ~/.config/agent-policy/sync_policy.py --check
```
