# Agent Skill (31 Shared How-To Playbooks)

## What It Is in Plain English

If [[40.01-Agent-Policy]] (`WORKSTYLE.md`) is the **always-on house rules**, an **Agent Skill** (`SKILL.md`) is an **on-demand recipe book**.

We keep **31 shared skills** in `~/.agents/skills/` and symlink them into [[10.02-Antigravity-AGY]], [[10.03-Codex-CLI-and-Spark]], [[10.04-Hermes-Agent]], and [[10.05-OpenCode-and-Maestri]]. That way, an agent doesn't waste context window tokens reading 31 playbooks on every turn—it only opens the one `SKILL.md` file it needs when you ask for that specific task.
