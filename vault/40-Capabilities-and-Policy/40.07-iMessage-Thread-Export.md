# Verified Thread Export (Proving Zero Dropped Messages)

## What It Is in Plain English

When you ask an AI to analyze a long message thread, most export scripts silently drop inline replies, mangle timestamps, or miss messages stored in macOS's binary `attributedBody` column.

We built the `imessage-export` [[40.03-Agent-Skill]] (`imessage_export.py` using pure Python standard library) so even a small local model can export a single conversation from `chat.db` in **strict read-only mode** and mathematically prove that **100% of messages, speakers, inline reply links, and read receipts match the database**.

---

## 3 Cool Bugs It Solves Automatically

1. **Decoding Hidden Text (`attributedBody`)**: On modern macOS, `message.text` is often blank (`NULL`) because Apple stores the text inside a binary blob. Our decoder cleanly recovered **427 out of 427** tested rows.
2. **Real Inline Replies (`thread_originator_guid`)**: Other tools (like older `imsg` builds) falsely marked 97 out of 113 normal messages as "replies." Our script checks the true thread pointer so you always know which specific bubble someone replied to.
3. **Built-In Proof Step (`verify`)**: After exporting, running `verify` re-checks every single row against the live SQLite database and confirms `"problems": []`.
